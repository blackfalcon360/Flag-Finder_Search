# Flag Finder — دنیا کے جھنڈے

Package name: `flagfinder.blackfalcon.jan`

Android app with the flags of ~197 countries.
- Pick the colors you see in a flag → matching countries are listed (closest matches first)
- "Only these colors" → exact color match
- Continent filter (Asia, Africa, Europe, N. America, S. America, Oceania)
- Search box: country name (English / Urdu), capital, currency, language
- Every country shows: continent, capital, official language(s), currency
- Country data lives in `app/src/main/assets/countries.txt` (one line per country) — easy to edit

## Build the APK with GitHub
1. Create a new GitHub repository and upload everything in this folder.
2. Open the **Actions** tab → **Build APK** (runs automatically on every push).
3. When it finishes, download **FlagFinder-debug-apk** from the run's Artifacts, unzip it and install the APK.
